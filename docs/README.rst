=======
Librito
=======

``librito`` est un environnement de travail pensé pour l'agentique permettant de convertir des histoires en livres illustrés.

Cette solution fournit un cadre de travail pour définir tous les composants d'un livre illustré, ainsi que les instructions, préconfigurées pour la plupart des environnements de *vibe-coding*, décrivant comment transformer une histoire en tous les éléments constitutifs d'un livre illustré.

.. warning::

    Ce projet est **en cours de développement**. Il n'a pas encore atteint un état stable, et nous vous recommandons de l'utiliser avec précaution le temps qu'une version stable soit publiée.
