=======
Librito
=======

Welcome to ``librito``, a lightweight CLI helper to generate illustrated storybooks from natural language stories.

Getting Started
===============

To get started, clone this repository and install the required dependencies:

.. code-block:: bash

    git clone git@github.com:Ahmed-AmineHomman/librito.git
    cd librito
    pip install -r requirements.txt

You're set!
